# A股价值发现选股系统 · 设计规格

> 日期：2026-06-01 | 状态：设计确认

## 1. 项目概述

一个基于基本面+技术面复合打分的 A 股选股系统，每日从全市场 4000+ 只股票中筛选出 **1-2 只最被低估的标的**，命令行运行。

### 核心目标

- 找到被市场低估且有技术面启动信号的股票
- 每天最多输出 1-2 只，宁缺毋滥
- 所有因子权重/阈值 YAML 配置驱动，可迭代优化
- 内置回测验证打分模型的有效性

## 2. 架构：五层流水线

```
数据采集层 → 基本面筛选层 → 技术面打分层 → 复合评分层 → 输出&回测
data/         fundamental/     technical/      scoring/      output/
```

## 3. 数据采集层

### 数据分类

| 类别 | 字段 | 来源 | 频率 |
|------|------|------|------|
| 估值 | PE/PB/PS/PCF、分位数(1/3/5年)、股息率 | akshare stock_a_lg_indicator | 每日 |
| 财务 | 营收/利润/现金流、ROE/ROA、毛利率、资产负债率、现金流/净利比 | akshare + 东方财富 | 每季 |
| 行情 | 日线/周线/60分钟 OHLCV | akshare stock_zh_a_hist | 每日 |
| 资金流向 | 北向资金、主力净流入、大单分布 | akshare + 东方财富 | 每日 |
| 排雷 | 商誉/净资产、股权质押、大股东减持、ST风险 | akshare + 巨潮资讯 | 每日 |
| 行业 | 申万行业分类、行业 PE/PB 中位数 | akshare | 每日 |
| 前瞻 | 业绩预告、业绩快报、分析师预期 | akshare stock_em_yjyg/yjkb | 每日 |

### 三级漏斗

1. **全量** ~4000 只 → 剔除 ST/*ST/上市<180天/停牌
2. **初筛后** ~1000 只 → 排雷：商誉>50%淘汰、质押>60%淘汰、连续2季亏损淘汰
3. **精细计算** 前 200 只 → 基本面打分后取前200做技术面完整计算

### 性能 & 容错

- 本地缓存：财务数据缓存为 Parquet，行情按日增量追加
- API 降级：akshare 不稳定时降级到本地缓存 + 东方财富爬虫
- 单次运行目标：< 5 分钟

## 4. 基本面打分模型

### 因子结构

| 维度 | 权重 | 子因子 |
|------|------|--------|
| **估值** | 35% | PE分位(30%) + PB分位(25%) + PS分位(20%) + PE绝对值(15%) + 股息率(10%) |
| **成长** | 25% | ROE(30%) + ROE趋势(15%) + 营收增速(20%) + 利润增速(20%) + 毛利率趋势(15%) |
| **质量** | 25% | 资产负债率(25%) + 经营现金流/净利(30%) + 商誉/净资产(25%) + 股权质押(10%) + 大股东减持(10%) |
| **预期** | 15% | 业绩预告方向(30%) + 分析师预期上调(25%) + 预收账款/合同负债(20%) + 现金流趋势(15%) + 管理层增持(10%) |
| **合计** | 100% | 35+25+25+15 = 100%（新增预期维度，从估值/成长/质量各让5%） |

### 关键设计

- PE/PB/PS 全部用**同行业 5 年分位数**做对比，不做跨行业绝对值比较
- 子因子线性映射 0-100 分：`min(100, max(0, 100 × (实际值 - 下限) / (上限 - 下限)))`
- 硬淘汰规则在打分前执行：PE>50、商誉>50%、质押>60%、连续亏损

## 5. 技术面打分模型

### 因子结构

| 维度 | 权重 | 子因子 |
|------|------|--------|
| **趋势** | 35% | EMA20/50金叉(25%) + 价格vs EMA200(20%) + ADX强度(20%) + 均线排列(20%) + 布林带(15%) |
| **动量** | 25% | RSI位置(30%) + MACD状态(30%) + KDJ位置(15%) + 价格动量(15%) + RSI背离(10%) |
| **量价** | 20% | 放量上涨(35%) + 量比(20%) + OBV趋势(20%) + 换手率(15%) + 主力资金净流入(10%) |
| **形态** | 10% | W底/头肩底/杯柄/三角旗形/底部盘整突破 识别 |
| **多周期** | 10% | 周线(50%) + 日线(35%) + 60分钟(15%) 一致性判断 |

### 共振加成

- 趋势+动量同时≥60 → +10%
- 趋势+量价同时≥60 → +10%
- 趋势+动量+量价三者≥60 → +20%
- 形态看涨+周线多头 → +15%

### 多周期铁律

- 周线看空 → 技术面总分 = 0（大周期压制）
- 三周期一致看多 → 多周期因子满分

## 6. 复合评分

```
最终得分 = 基本面总分 × 0.60 + 技术面总分 × 0.40
```

置信度标签：
- ≥80 分 → ⭐⭐⭐ 高置信
- 60-79 分 → ⭐⭐ 中置信
- <60 分 → ⭐ 低置信

## 7. CLI 输出

```
python main.py                    # 当日选股
python main.py --top 5            # 输出前5只
python main.py --backtest         # 运行回测
python main.py --date 2026-01-15  # 指定日期跑选股
```

每只票输出完整打分卡，展示所有子项得分和关键数据依据。

## 8. 回测验证

- 历史任一天运行打分 → 跟踪 N 日后实际收益率（20/60/120日）
- 输出指标：Top N 平均收益、vs 沪深300超额、胜率、IC、分层收益曲线
- 参数优化：遍历权重组合（步长 5%），输出最优配置建议

## 10. 技术栈

- Python 3.10+
- akshare：主数据源
- pandas / numpy：数据处理
- pyyaml：配置文件
- requests + beautifulsoup4：爬虫补充

## 11. 边界 & 不做的事

- **不做** Web 界面 / 仪表盘
- **不做** 实时推送通知（V1 阶段）
- **不做** 自动下单交易
- **不做** 深度学习形态识别（规则引擎即可）
- **不做** 数据库持久化（本地文件缓存足够）
- **不处理** 除 A 股以外的市场
